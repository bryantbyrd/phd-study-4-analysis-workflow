# PhD Study 4 Analysis Workflow

This repository contains an R/Quarto workflow for organizing statistical analyses from my PhD Study 4 project.

The goal of this repository is to document the analysis workflow used for matched-pair performance outcomes and biomarker linear mixed model analyses.

## Analyses Included

This workflow includes:

- Data cleaning and restructuring
- Matched-pair IPC vs Sham performance analysis
- One-sample t-test against zero
- Linear mixed models for biomarker outcomes
- Estimated marginal means
- Pairwise comparisons
- Model diagnostics
- Publication-style biomarker figure workflow

## Biomarkers

The biomarker analysis workflow includes:

- CRP
- IL-6
- IL-10
- TNF-alpha
- TAC

## Tools Used

The original research data are not included in this repository.
